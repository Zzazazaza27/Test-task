# Order Synchronizer (Мини-синхронизатор заявок)

Микросервис для сбора «сырых заявок» из внешнего API (`https://test.ooobs.ru/api/orders`), нормализации телефонных номеров, идемпотентной дедупликации и отдачи агрегированной статистики.

## Требования задания и реализация

1. **Нормализация телефонов**: 
   - Из номера удаляются любые нецифровые символы.
   - Номера из 11 цифр, начинающиеся с `7` или `8`, а также 10-значные номера приводятся к единому формату `+7XXXXXXXXXX`.
   - Любые другие форматы (короткие, некорректные) отбрасываются как невалидные (`invalid_dropped`).

2. **Дедупликация по номеру телефона**:
   - При совпадении телефонов оставляется запись с максимальным значением `amount`.
   - При равных `amount` побеждает запись с более поздней датой `created_at`.

3. **Идемпотентность**:
   - Повторные запуски синхронизации не плодят дубли и сохраняют детерминированный результат (транзакционное сохранение в SQLite).

4. **Формат ответа JSON**:
```json
{
  "clients": [
    { "name": "Иван П.", "phone": "+79991234567", "email": "", "amount": 5000 }
  ],
  "stats": {
    "received": 17,
    "unique": 8,
    "duplicates_merged": 5,
    "invalid_dropped": 4
  }
}
```

## Хранение секретов и архитектурное решение

- **Секреты и конфигурация**: Хранятся в переменных окружения (`.env` файл для локальной разработки, в репозиторий не коммитится, пример в `.env.example`). В продакшене переменные инжектятся через systemd / Docker environment.
- **Почему такое решение**: 
  - Высокая надежность и производительность без сторонних зависимостей (чистый Python 3 / FastAPI).
  - Хранение состояния в SQLite с транзакционным UPSERT обеспечивает строгую идемпотентность и fallback на кеш при сбоях апстрима.
  - Поднят на боевом сервере под Nginx с SSL (Let's Encrypt).

## Запуск

### Локально (FastAPI / Uvicorn):
```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --port 8080 --reload
```

### Автономный запуск (без зависимостей):
```bash
python3 standalone_server.py
```

### Тесты:
```bash
pytest -v
```
